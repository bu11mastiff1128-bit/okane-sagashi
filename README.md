# おかねさがし　アプリ化キット（v1.0.0）

Claude Code（アプリ版）でこのフォルダを開き、次のように頼めば進められます。作業内容は `CLAUDE.md` に書いてあります。

> CLAUDE.md を読んで、Android版をPixelに入れて、iPhone用をGitHub Pagesに公開して

```
docs/      iPhone用（GitHub Pagesで公開して、ホーム画面に追加して使う）
android/   Android用（Kotlinのプロジェクト）
tools/     更新用のスクリプト
```

データ（所持金・家具・進み具合）は端末ごと・アプリごとに保存され、共有されません。

---

## 自分でやる必要がある操作

Claude Code が進められない、持ち主の操作が必要な部分です。

### Pixel：USBデバッグをオンにする（初回だけ）

1. 「設定」→「デバイス情報」→「ビルド番号」を7回タップ
2. 「設定」→「システム」→「開発者向けオプション」→「USBデバッグ」をオン
3. PixelをiMacにUSBでつなぎ、Pixelに出る確認で「許可」

### GitHub：ログインする（初回だけ）

1. GitHubのアカウントが無ければ https://github.com で作る
2. iMacの「ターミナル」で `gh auth login` を実行し、表示に従ってブラウザでログイン
   （Claude Code から頼まれたときで大丈夫です）

### iPhone：ホーム画面に追加する

1. iPhoneの **Safari** で、Claude Code が伝えた公開URL（`https://ユーザー名.github.io/okane-sagashi/`）を開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. ホーム画面のアイコンから起動する。一度起動すれば機内モードでも遊べます

---

## 注意

- iPhone用は公開リポジトリに置くため、URLを知っている人は誰でも開けます（データは各自の端末内なので、所持金などは見られません）
- iPhoneでは、Safariで遊んだ分とホーム画面のアプリで遊んだ分は別々に保存されます。ホーム画面から使ってください
- Androidはアプリを削除するとデータも消えます。上書きインストール（更新）なら残ります
